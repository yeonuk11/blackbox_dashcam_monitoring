## 상태

- 구현 진입점: `predict.py` 의 `predict(data_dir, model_dir)`
- 출력: `ID`, `collision_frame`, `entry_frame`, `evasion_space`, `entry_side`
- 리더보드 실측 **S2 = 0.5670819219** (종합 0.65712 를 낸 제출 80481 과 같은 코드)
- 이 폴더의 `stage2_*.py` 는 그 제출본과 **바이트 단위로 동일**합니다.
  팀 패키지에 맞추느라 바뀐 것은 아래 "이식 시 변경점" 세 가지뿐입니다.

## 모델과 추론

파이프라인은 한 덩어리가 아니라 4열을 각각 다른 경로로 냅니다.

- **공통 전단**: 폴더의 JPEG 를 균일 격자로 읽어(1250프레임이면 전 프레임)
  DIS 광류 + 프레임차 + 파인튜닝 ConvNeXt-tiny 3-band 블록을 만듭니다.
- **collision_frame**: 3-net 앙상블(`best.pt` + `v2_fold0` + `v2_fold1`) × flip-TTA 의
  프레임별 히트맵을 평균한 뒤, 자기 ±0.3s 박스카 안의 **질량 최대** 지점을 고르고
  실제 존재하는 프레임 번호로 스냅합니다(피크가 아니라 질량인 것이 중요합니다).
- **entry_frame**: 같은 앙상블의 진입 히트맵을, argmax 를 **충돌 인덱스 이하로 제한**해
  디코딩합니다. 리드 상한은 두지 않습니다(0.0 = 무제약).
- **entry_side**: 세 표의 부호 합 — ① 미러 대칭화한 side 로짓(flip-TTA 가 헤드의
  "LEFT 쏠림"을 상쇄) ② 접촉 직전 1초의 열별 프레임차 에너지(가중치 5.0)
  ③ FOE 잔차 횡방향 오프셋(가중치 10.0).
- **evasion_space**: 대칭화한 evasion 로짓에 고정 바이어스(−1.5)를 더해 0/1.

체크포인트·디코더 모두 온라인 다운로드 없이 `model_dir` 안에서만 읽습니다.

### 디코딩 실패 정책

한 폴더가 깨져도 세 stage 전체를 오류로 만들지 않습니다. 학습 모델이 실패하면
경고를 남기고 그 폴더 자신의 프레임 번호 범위 안에서 계산한 기본값을 씁니다
(존재하지 않는 프레임 번호는 절대 내지 않습니다). 모든 ID 에 대해 항상 한 행이 나갑니다.

## 이식 시 변경점 (원 제출본 대비)

팀 패키지 구조에 맞추느라 바꾼 것은 이 셋뿐이고, 어느 것도 예측값을 바꾸지 않습니다.
같은 10개 실폴더에서 원 제출본과 4열 전부 일치를 확인했습니다.

1. **모듈명 접두사** — `common.py` → `s2common.py`, `model_io.py` → `s2model_io.py`,
   `stage3_features.py` → `s2flow.py`. 다른 stage 가 같은 이름을 번들하면
   먼저 import 된 쪽이 이기는 `sys.modules` 충돌이 나기 때문입니다.
   (Stage 2 는 광류 추출기를 Stage 3 과 공유합니다. 팀 규약상 다른 stage 모듈을
   import 할 수 없어 사본을 넣었습니다.)
2. **`sys.path` 에 이 폴더 추가** (`predict.py` 상단) — 모듈들이 서로를
   `import stage2_features` 처럼 최상위 이름으로 부릅니다. `stage2_` 접두사라
   다른 stage 와 부딪히지 않습니다.
3. **앙상블 탐색 경로에 모듈 자기 폴더 추가** (`stage2_model.py`) — 원래는
   flat submit.zip 배치(`here/model/stage2`)만 봤는데, 팀 구조에서는 가중치가
   모듈과 같은 폴더에 있습니다. 경로 추가는 가산적이라 기존 배치도 그대로 동작합니다.

## 알려진 제약

- **60분 예산**: 원 코드는 `sec_per_item` 을 받아 남은 시간에 맞춰 읽을 프레임 수를
  줄입니다. 팀 계약의 `predict(data_dir, model_dir)` 에는 그 신호가 없어서
  현재는 항상 전 프레임을 읽습니다(폴더당 약 4초, 실측). 세 stage 합산 60분
  제한이 빠듯해지면 stage 별 시간 배분 합의가 필요합니다.
- **회피공간**: 도메인 밖에서는 파일별 정보가 거의 없어 2클래스 macro-F1
  상한(≈0.5) 근처입니다. 실라벨 검증면이 아직 없어 개선 여지를 측정하지 못했습니다.
